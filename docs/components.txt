package components // import "github.com/elaous/gojiberry/components"

Package components is a small library of ready-made xango components:
plain Go functions taking a typed props struct and returning a xango.Node,
the same shape as any other component in this framework (see the root README's
"Components" section). None of them import domrt or syscall/js directly --
interactive ones take the current state and On* event handlers as props (the
same controlled-component pattern the wasm-counter example uses), so a single
component works unchanged for SSR-only pages and for a WASM page driving it with
domrt.Mount/Update.

    message id ("saver.save"), or def, the English the component has, when it
    has none. It is the identity until an app sets it, once, before the first

var TranslatePlural = func(id, one, other string, n int) string {
	m := other
	if n == 1 {
		m = one
	}
	return fmt.Sprintf(m, n)
}
    TranslatePlural is how the components say a message that depends on a
    number: the text for the id in the plural form of n, with n put in. one and
    other are the English the component has. It is English's rule until an app
    sets it (package i18n has Catalog.Plural):

        components.TranslatePlural = func(id, one, other string, n int) string { return cat.Plural(lang, id, one, other, n) }


FUNCTIONS

func A11yBlockAt(blocks []A11yBlock, offset int) int
    A11yBlockAt returns the index of the mapped block that holds the stream
    offset (the caret), -1 if none does (the offset is on a paragraph break that
    belongs to no block, or the blocks are not mapped). The end of a block's
    text is still in it.

func AccessibleText(p AccessibleTextProps) xango.Node
    AccessibleText is the document's text for assistive technology: one element
    per block, in order, with real heading, list, quote and table markup.
    The links are real links, the first row of a table holds column headers
    (th scope="col"), the headings are listed in a navigation landmark (the
    outline), commented text and suggested changes are marked, and the comments
    follow in a region of their own.

func Accordion(props AccordionProps) xango.Node
    Accordion renders a vertical stack of collapsible sections.

func Alert(props AlertProps) xango.Node
    Alert is a Dialog preset for a single acknowledgment, rendered with
    role="alertdialog" (per ARIA, for a dialog demanding an immediate response)
    instead of Dialog's default role="dialog".

func Announcer(message string) xango.Node
    Announcer is a live region: when its message changes, a screen reader says
    it (politely, after what it is already saying). Keep it in the page and
    change the message; "" says nothing.

func Avatar(props AvatarProps) xango.Node
    Avatar renders a profile picture, or a colored circle of Initials when Src
    is empty (e.g. the user hasn't uploaded one).

func BookmarkList(props BookmarksProps) xango.Node
    BookmarkList renders the bookmarks with the text each is on; clicking one
    goes there and, for an editor, Remove takes it off. The link form "#name" is
    shown, to type into a link.

func Box(props BoxProps) xango.Node
    Box is a layout container, normally full height, split into however many
    sub-boxes Divisions describes -- each independently sized by percentage,
    a fixed unit value, or left flexible to fill whatever height its siblings
    don't claim. Built on CSS Grid's grid-template-rows, which already handles
    exactly this mix of units in one declaration.

func Breadcrumbs(props BreadcrumbsProps) xango.Node
    Breadcrumbs renders a trail of links with the last item marked as the
    current page (aria-current, and rendered as plain text even if it has an
    Href -- you're already there).

func Button(props ButtonProps) xango.Node
    Button renders a styled <button>.

func Capacity(p CapacityProps) xango.Node
    Capacity shows how full a store is: a meter with the percentage, how much
    is used of how much was allocated, and how much is left. A meter above 90%
    is marked, and one over 100% too. From CapacityWarnAt percent a notice says
    what to do so that no work is lost.

func CapacityAdvice(pct float64) string
    CapacityAdvice is what to do when a store is filling up, in words for the
    person.

func Carousel(props CarouselProps) xango.Node
    Carousel renders a single active slide, prev/next arrows, and a dot per
    slide for direct navigation. All slides are rendered (the inactive ones
    aria-hidden) so this works before any client-side hydration runs, with CSS
    choosing which one shows.

func CheckPanel(p CheckPanelProps) xango.Node
    CheckPanel lists the findings of a document accessibility check, each
    with its fix and a button that goes to it. The summary is a live status,
    so a reader hears the result of pressing Check.

func Checkbox(props CheckboxProps) xango.Node
    Checkbox renders a single labeled checkbox, the label wrapping the input so
    clicking the text toggles it too (same zero-JS trick FileUploader's dropzone
    label uses).

func CheckboxGroup(props CheckboxGroupProps) xango.Node
    CheckboxGroup renders a set of independent checkboxes -- unlike RadioGroup,
    any number (including all or none) may be checked at once.

func Chip(props ChipProps) xango.Node
    Chip renders a small labeled pill, optionally with a leading icon and a
    remove button.

func ChordFromKey(k xango.KeyData) (chord string, ok bool)
    ChordFromKey builds the chord string (canvas.Chord) for a key press,
    reading letters and digits from the physical key the way the canvas does.
    ok is false for a press of a modifier on its own, and for one with no Ctrl,
    Cmd or Alt (the canvas only runs shortcuts that have one).

func Collab(props CollabProps) xango.Node
    Collab wraps a shared document's content and, based on Role's capabilities,
    gates what the current collaborator can see and do with it: viewers get
    read-only Content plus a "View only" badge and nothing else; editors
    also get Actions and Comments; owners also get Delete/Share. Collab has
    no networking or persistence of its own -- it's a pure permission gate,
    the same "current state + On* callbacks" pattern every interactive component
    in this package already uses. Pair it with your own real-time sync (e.g.
    domrt/browser.Socket) to make Content/Comments actually collaborative;
    see examples/collab-editor-app for one way to wire that up.

    Collab only gates the affordances *around* Content -- Actions/
    Delete/Share/Comments -- since Content is an opaque []xango.Node it
    can't reach into. The gj-collab-readonly class it adds when !CanEdit
    is purely cosmetic (a slight opacity change); if Content includes a
    real input/textarea, making it genuinely non-interactive for a viewer
    (not just visually muted) is the caller's job, e.g. Textarea's own
    Disabled field driven off the same CapabilitiesForRole(Role) call.
    examples/collab-editor-app does exactly this.

func ColorPicker(props ColorPickerProps) xango.Node
    ColorPicker renders a styled native color input, letting the browser handle
    the actual color-picker UI.

func CommandMaterial(command string) string
    CommandMaterial is the symbol name for an editing command (its
    canvas.Command string, "bold", "para.align-left"...), or "" for none.

func CommentCard(props CommentCardProps) xango.Node
    CommentCard renders one comment: author and time, the commented text,
    the Markdown body with mentions highlighted, its replies and, for an editor,
    Resolve/Reopen, Delete and a reply box.

func CommentList(props CommentListProps) xango.Node
    CommentList renders the comments as cards, filtered by status (open,
    resolved or all) with a count on each choice.

func Confirm(props ConfirmProps) xango.Node
    Confirm is a Dialog preset for a yes/no decision, rendered with
    role="alertdialog" (per ARIA, for a dialog demanding an immediate response)
    instead of Dialog's default role="dialog".

func ContextMenu(props ContextMenuProps) xango.Node
    ContextMenu renders a positioned menu (typically opened from a right-click
    -- see html.Element.OnContextMenu) plus a full-viewport backdrop that closes
    it on an outside click. Renders nothing when !Open.

func ContextProvider(parent context.Context, key *ContextKey, value any, render func(ctx context.Context) xango.Node) xango.Node
    ContextProvider is gojiberry's answer to the open design question
    docs/ROADMAP.md (task #129) posed for a Context API: unlike a component
    library built on a stateful class-component tree (React et al.), every
    component in this package is a plain, stateless function of its own props
    (see the root README's own "A ready-made component library" section) --
    there is no implicit, ambient scope a deeply-nested component could read a
    value out of without it having been passed somehow, in *either* rendering
    mode. A xango.Node tree is built eagerly, one plain Go function call at a
    time, entirely before xango.Render/domrt.Mount ever walks it -- so by the
    time either renderer sees the tree, there's no "current context" left to
    consult; whatever a descendant needed had to already be resolved during that
    eager build, the same constraint that makes keyed fragments need dedicated
    .xg syntax rather than a runtime trick (see xango's own Frag/WithKey doc
    comments).

    The answer here is the same one stdlib's own context.Context is designed
    for: an explicit, ordinary Go value threaded through an explicit call chain,
    never a hidden global (which also wouldn't be safe under concurrent SSR
    requests rendering different pages in separate goroutines at once).
    render receives ctx with value already attached under key, and returns
    whatever subtree that lets it build -- typically by reading it back with
    ContextValue and handing it down as an ordinary prop to whatever actually
    needs it, or by wrapping a further nested ContextProvider of its own.
    This is deliberately *not* fully transparent the way React's Context is:
    an intermediate component between the Provider and the real consumer still
    has to accept and forward ctx itself (or the extracted value) to reach a
    descendant several layers down. What it does buy over plain prop-drilling is
    that the intermediate layers only ever thread one generic context.Context
    parameter, rather than growing a bespoke, unrelated prop of their own for
    every distinct value a deeper descendant happens to need.

func ContextValue[T any](ctx context.Context, key *ContextKey) (T, bool)
    ContextValue reads key back out of ctx -- ok is false if key was never
    attached anywhere up ctx's own chain, or if the value stored under it isn't
    a T.

func DataTable(props DataTableProps) xango.Node
    DataTable renders a sortable, optionally-selectable, optionally-
    searchable/paginated table -- see components/datatable.css.

func DatePicker(props DatePickerProps) xango.Node
    DatePicker renders a styled native date input, letting the browser handle
    the actual calendar UI/locale formatting/keyboard input.

func Dialog(props DialogProps) xango.Node
    Dialog is Modal with the common title/body/footer-actions shape.

func DocList(p DocListProps) xango.Node
    DocList lists documents, each with the operations the host plugs in: Open,
    Duplicate, Trash, Delete and a tag editor, and above them a filter by tag.

func DocumentView(props DocumentViewProps) xango.Node
    DocumentView lays out a word-processor window around a canvas editor,
    the way Google Docs does: the title and a menu bar across the top, a toolbar
    under them, the document on a grey desk in the middle with an optional
    sidebar beside it, and a status line at the bottom. It is plain structure
    -- header, toolbar, main (desk and sidebar), footer -- with a stylesheet
    (documentview.css); everything inside is yours.

func Dropdown(props DropdownProps) xango.Node
    Dropdown renders a closed control button and, when Open, a listbox of
    options below it (the ARIA listbox pattern). Keyboard: Down or Up on the
    button opens the list and goes to its first or last option; Up, Down,
    Home and End move among the options, Enter or Space chooses one, Escape
    closes the list with the focus back on the button, Tab closes it and leaves
    (see listboxkeys.go).

func ErrorView(id string, err error) xango.Node
    ErrorView draws err for a person: the message (an alert, so a screen reader
    says it at once) and, under a native Details disclosure, the technical text
    with a Copy button when CopyText is set. The id is the element that holds
    both.

func FidelityPanel(p FidelityPanelProps) xango.Node
    FidelityPanel shows what a file format changes in the document before it
    is exported, and what the last file imported left out: each feature the
    document uses that the format drops or simplifies, with how it is written.
    The summary is a live status, so a reader hears it when the format is
    chosen. Nothing here blocks an export; it tells the person what the file
    will not hold.

func FileUploader(props FileUploaderProps) xango.Node
    FileUploader renders a dropzone that's also a native file-input label
    (clicking anywhere on it opens the file browser, no JS needed for that part)
    plus an optional progress bar.

func FindReplace(p FindReplaceProps) xango.Node
    FindReplace is the find and replace bar: a query box with the match count
    and previous and next buttons, toggles for case, whole word and regular
    expression, and a replacement box with Replace and Replace all.

func Floating(props FloatingProps) xango.Node
    Floating makes Children float above the surrounding content at a fixed
    corner/edge position -- a formalized version of the "wrap one or more Toasts
    in your own position:fixed container" idiom Toast's own doc comment already
    describes, generalized to any content: a floating action button, a badge,
    a persistent status widget, or a Toast stack.

func FolderPicker(p FolderPickerProps) xango.Node
    FolderPicker is the control for saving to a folder on the person's computer:
    Choose folder, and once one is chosen its name with Forget, or, when the
    browser has withdrawn permission after a restart, "Reconnect folder" (the
    saves to it wait until then).

func FontSelector(props FontSelectorProps) xango.Node
    FontSelector renders a closed control showing the chosen family in its own
    typeface and, when Open, a panel with a search box, source filter chips and
    a list of fonts each previewed in itself. It is controlled: the caller owns
    Open, Query and Source (see the root README's controlled-component notes)
    and loads the fonts it lists (for fonts with URLs, add fonts.FontFaceCSS to
    the page).

    Like Dropdown it implements the ARIA listbox pattern's attributes only;
    it has no keyboard navigation of its own.

func FootnoteList(props FootnoteListProps) xango.Node
    FootnoteList renders the numbered footnotes, their text as Markdown;
    clicking a number goes to its mark and an editor gets Edit and Delete.

func FormatChord(chord string, mac bool) string
    FormatChord writes a key chord ("Mod+Alt+Shift+K") for people: "Ctrl+
    Alt+Shift+K", or on a Mac "⌃⌥⇧K" with ⌘ for Mod.

func Grid(props GridProps) xango.Node
    Grid is a plain CSS Grid layout container: arranges Children into a grid,
    normally filling its parent's own width, with Columns/Gap controlling
    track sizing and the spacing between cells -- Box's own sibling for a
    two-dimensional layout instead of Box's single-axis stacked divisions. This
    is a layout primitive, not a data-display component: it has no notion of
    rows, selection, sorting, or pagination at all -- reach for DataTable when
    what's actually being browsed is tabular data, Grid when the job is just
    arranging an arbitrary set of already-built children into a responsive grid.

func HasMaterial(name string) bool
    HasMaterial says whether Material knows the name.

func HeadingBreadcrumb(entries []canvas.OutlineEntry, index int) string
    HeadingBreadcrumb is HeadingPath as one line, "Chapter › Section".

func HeadingPath(entries []canvas.OutlineEntry, index int) []string
    HeadingPath is the headings the caret is under, from the top one down: the
    heading at index (OutlineIndexAt) and the nearest shallower one before it,
    and so on up. It is empty when index is -1.

func Icon(props IconProps) xango.Node
    Icon renders a small inline glyph, sized and colored via CSS. It's
    deliberately text (a Unicode character), not an inline <svg>: domrt's
    client-side Mount/Update create elements with plain createElement, which
    builds the wrong (HTML, not SVG) namespace element for <svg>/ <path>/etc.,
    so any such tree silently fails to render once mounted client-side even
    though it looks fine in server-rendered HTML (see Progress's circle variant,
    and domrt/svg's own doc comment, for the same constraint solved the same
    way elsewhere in this package). For a real vector icon that must render
    client-side, build it yourself with domrt/svg.CreateElement and pass it
    through one of this package's existing Icon *xango.Node slots (Chip,
    Dropdown, ContextMenu) instead.

func ImageZoom(props ImageZoomProps) xango.Node
    ImageZoom renders a thumbnail that, when Zoomed, also shows a full-viewport
    overlay with the same image enlarged -- a Modal-style backdrop (see Modal's
    doc comment for why backdrop and content are DOM siblings, not nested:
    so a click on the enlarged image itself can't be mistaken for a click on the
    backdrop behind it).

func KeyBindings(props KeyBindingsProps) xango.Node
    KeyBindings renders the key bindings editor: every command with its
    shortcut, a search box, and per row Change (press the new keys),
    Clear and Reset. It is controlled: the caller owns Recording and applies
    OnBind/OnClear/OnReset to the Stage (canvas.Stage.Rebind) and says what
    happened in Message. A modifier-only press is ignored and Escape cancels.

func LanguagePanel(p LanguagePanelProps) xango.Node
    LanguagePanel shows the detected language, a translator for the selection
    and the grammar issues with the fix for each.

func Link(props LinkProps) xango.Node
    Link renders a styled <a>. A disabled link renders as a non-interactive
    <span> instead of an <a> without an href, since an anchor's disabled-looking
    states aren't real disabled controls to assistive tech the way a <button
    disabled> is.

func LinkHost(raw string) string
    LinkHost returns the host part of a URL for display ("example.com"),
    or the URL itself if it does not parse.

func LinkPreview(props LinkPreviewProps) xango.Node
    LinkPreview renders a small card for a link: its image, title, description
    and site. With only a URL it shows the host; renders nothing without one.
    The card is itself a link to the URL.

func List[T any](props ListProps[T]) xango.Node
    List renders a ul/ol with one li per item, each produced by the Item render
    prop. It is the smallest generic component: it shows how a component can
    take typed data and a function that turns an item into markup.

func Loader(props LoaderProps) xango.Node
    Loader renders a spinning indicator for an in-progress operation with no
    known completion percentage -- see Progress for one that has one.

func MarkdownText(text string) xango.Node
    MarkdownText renders Markdown for a comment: paragraphs, bullet and
    numbered lists, quotes, headings (as bold lines), and the inline forms of
    inlineNodes, with @username and e-mail mentions highlighted. Raw HTML is
    shown as text, and only http, https and mailto links are live.

func Material(name string) xango.Node
    Material draws a Material Symbols icon (outlined) by its name
    ("format_bold", "delete", "link"): an element that takes the text colour
    and a size of 1.25em, hidden from assistive technology because the button or
    menu entry around it carries the name. The names are the ones opendocs uses,
    so a button moves between the two unchanged. An unknown name draws nothing.
    (Icon is the small built-in set of text glyphs; Material is the full-size
    drawn icons.)

    It is a plain <span> whose shape is a CSS mask made from the icon's path,
    not an inline <svg>: the DOM runtime creates elements without the SVG
    namespace, so an <svg> built client-side would not draw. The glyphs are
    Apache-2.0 licensed (see material_data.go) and are in the binary as path
    data, not as a font: only the names in MaterialNames are included.

func MaterialNames() []string
    MaterialNames lists the symbols available, sorted.

func Menu(props MenuProps) xango.Node
    Menu renders a clean, lightweight menu: a list of entries with optional
    shortcuts, check marks, separators and nested submenus. It holds no state --
    submenus open with CSS (:hover, :focus-within) -- and has no position of its
    own: put it in whatever popup or panel you like, or use MenuBar for a bar of
    them. It is built from plain <ul>/ <li> with ARIA menu roles; its stylesheet
    is menu.css.

func MenuBar(props MenuBarProps) xango.Node
    MenuBar renders a row of menus (File, Edit, ...), at most one open at a
    time. It is controlled: the caller owns Open. A click anywhere outside
    closes it.

func Migrate(p MigrateProps) xango.Node
    Migrate is the panel for moving documents in from another platform (Google
    Docs, Microsoft Word on OneDrive) or from Word files on this computer:
    choose the platform, sign in with a token, browse its folders, tick what
    to bring and start; progress and a report of what could not be migrated are
    shown.

func Modal(props ModalProps) xango.Node
    Modal renders a full-viewport backdrop plus a centered content box. Renders
    nothing when !Open. This is the base Dialog (and, through it, Confirm and
    Alert) builds on; use it directly for fully custom modal content.

func ModalKeys(onClose func()) xango.Attr
    ModalKeys is the keydown handler of a modal box: Tab and Shift+Tab
    move the focus round the focusable elements inside it, wrapping at
    the ends (and from the box itself, which has the focus when it opens,
    to the first or the last), so the focus cannot leave it for the page behind;
    Escape calls onClose, if there is one (the same as a click on the backdrop).
    Keys with Ctrl, Alt or Meta are left alone.

func OTPInput(props OTPInputProps) xango.Node
    OTPInput renders Length single-character text boxes for entering a
    one-time-passcode/verification code.

func OpenDownloadDialog(d OpenDownload) xango.Node
    OpenDownloadDialog is the dialog of an OpenDownload: the size of the current
    version and of the history, a checkbox to drop the history, and what the
    file will weigh.

func Outline(props OutlineProps) xango.Node
    Outline renders the document's headings as an indented list, the current
    one marked; clicking one reports it (go there with TextFlow.GotoOffset and
    ScrollView.RevealPending). It is controlled.

func PageSetupPanel(props PageSetupProps) xango.Node
    PageSetupPanel edits a PageSetup: paper, orientation, margin presets and
    each margin. It is controlled: it shows Setup and reports changes through
    OnChange.

func Pagination(props PaginationProps) xango.Node
    Pagination renders Prev/Next buttons plus page-number buttons, with an
    ellipsis collapsing the middle of a long run so it stays a constant width
    regardless of TotalPages. Renders nothing when TotalPages < 1.

func Passkey(p PasskeyProps) xango.Node
    Passkey is the sign-in and passkey-management control: "Sign in with a
    passkey" and "Create an account with a passkey" when nobody is signed in,
    and the person's passkeys with Add and Remove when someone is. A passkey
    is two factors in itself (the device, and the fingerprint, face or PIN that
    unlocks it), so there is no separate code to type; the control says so.

func People(p PeopleProps) xango.Node
    People lists who can open a document, each with a role to change and a
    Remove, and a form to invite someone. Like the other document components
    it knows nothing about where access is kept: a docstore ACL, an HTTP API,
    a test double.

func Popover(props PopoverProps) xango.Node
    Popover renders Trigger, and, when Open, a panel of Content anchored
    to it plus a full-viewport backdrop that closes it on an outside click.
    Unlike Tooltip (pure CSS hover), Popover is click-triggered and can hold
    interactive content of its own.

func Presence(props PresenceProps) xango.Node
    Presence shows who else is in the document -- a round avatar per person in
    their cursor color, with their name and role as the tip -- the state of
    the connection, and, for a viewer, a "View only" badge. It is controlled;
    feed it from collab.Session.

func Progress(props ProgressProps) xango.Node
    Progress renders a linear bar or a circular ring showing Value percent
    complete, or an indeterminate animation when the actual completion isn't
    known yet. The circle variant is drawn with a CSS conic-gradient rather
    than an <svg>: domrt's client-side Mount/Update creates elements with plain
    createElement, which produces the wrong (HTML, not SVG) element for an
    <svg>/<circle> tag, so an SVG-based ring would silently fail to render once
    mounted (server-rendered HTML wouldn't show the bug -- the browser's HTML
    parser switches namespace for a parsed <svg> tag on its own).

func ProposalPanel(p ProposalPanelProps) xango.Node
    ProposalPanel lists the suggested changes of a document with buttons to
    accept or reject each (and all), and a switch for suggestion mode. Each
    suggestion is a sentence ("Ana replaced 'brown' with 'red'"), so the list
    reads well without colors, and each button names the suggestion it is for.

func ProposalSentence(p canvas.Proposal) string
    ProposalSentence says a suggested change in a sentence: "Ana replaced
    'brown' with 'red'", "Ana added 'X'" or "Ana removed 'brown'". Long text is
    cut short.

func RadioGroup(props RadioGroupProps) xango.Node
    RadioGroup renders a set of mutually exclusive radio buttons.

func Recipients(p RecipientsProps) xango.Node
    Recipients lists the keys a document is encrypted to and shares it with one
    more. Adding a key shows its type, label and fingerprint and asks the owner
    to type the fingerprint, which they should have checked with the person (a
    pasted key for the wrong person is not added by a click alone). Removing one
    says what it does and does not do.

func RegisterErrorGroups(g ...ErrorGroup)
    RegisterErrorGroups adds groups that ExplainError tries before its own,
    in the order given (the most specific first). Call it once, before the first
    render. It exists so that a package can teach ExplainError the errors of a
    layer these components do not import (package components/encerr does it for
    the encrypting adapter).

func RemovedNotice(files int) string
    RemovedNotice is the line that says what a Remove did: how many stored files
    were encrypted again without the key.

func Saver(props SaverProps) xango.Node
    Saver renders the save form: pick a target and a format, name the document
    and save it, and below it the documents already saved there, each to open or
    delete. It is controlled (see the root README's controlled-component notes);
    saver.Session keeps its state and does the saving.

func Search(props SearchProps) xango.Node
    Search renders a text input plus, when Open, a listbox of Suggestions below
    it -- a basic implementation of the ARIA combobox pattern (role/aria-*
    attributes only, no keyboard navigation of its own, the same scope
    RadioGroup/Dropdown/etc. keep to elsewhere in this package).

func SizeText(n int64) string
    SizeText writes a size as the nearest whole KiB, MiB or GiB, with the exact
    bytes: "340 KiB (348,160 bytes)". Under 1 KiB it is just the bytes.

func Slider(props SliderProps) xango.Node
    Slider renders a styled native range input.

func SpellPanel(p SpellPanelProps) xango.Node
    SpellPanel lists the misspelled words with their suggestions, and an
    "Ignore" and "Add to dictionary" for each.

func StatusBar(props StatusBarProps) xango.Node
    StatusBar is the line at the bottom of a document window: items side by side
    (page setup, page count, save state, where the caret is in the headings,
    word count...). An item with no text is left out.

func StyleEditor(props StyleEditorProps) xango.Node
    StyleEditor renders controls for a canvas.Format -- font, size, weight,
    bold, italic, underline, strikethrough, superscript, subscript, text and

    subscript exclude each other; "clear" buttons (and an empty size) put a
    field back to inheriting from Base.

func StylePicker(props StylePickerProps) xango.Node
    StylePicker renders a gallery of named styles, each previewed in its own
    formatting -- paragraph styles first, then character styles -- the way a
    word processor's style list does. It is controlled: the caller applies
    the pick (see canvas.Styles for the commands, or TextFlow.ApplyParagraph /
    ApplyFormat with a Style).

func Suggestions(p SuggestionsProps) xango.Node
    Suggestions renders the popup list; nothing when the state is closed.

func SuggestionsControl(id string, s SuggestState) []xango.Attr
    SuggestionsControl is the attributes the editing element carries while it
    has the popup: role combobox, expanded, controlling the list, and naming the
    highlighted option.

func Switch(props SwitchProps) xango.Node
    Switch renders a toggle switch: a native checkbox (visually hidden but still
    keyboard/screen-reader accessible) styled as a sliding track and thumb via
    the CSS :checked sibling selector, the same "real control, custom look"
    approach FileUploader's hidden file input uses.

func SymbolCategories(symbols []Symbol) []string
    SymbolCategories lists the categories of symbols, in first-seen order.

func SymbolPicker(props SymbolPickerProps) xango.Node
    SymbolPicker renders a searchable grid of symbols to insert -- a search
    box, category chips, the recently used ones and the matching symbols,
    each a button titled with its name. It is controlled (Query, Category); the
    caller inserts the picked character where it belongs (for a canvas editor,
    FloatingText.InsertText or TextFlow.InsertText).

func TabIndex(selected bool) xango.Attr
    TabIndex is the tabindex of a tab: 0 for the selected one, -1 for the
    others.

func TabKeys(index, count int, onSelect func(index int)) xango.Attr
    TabKeys is the keydown handler of the tab at index among count: it moves the
    focus along the tablist and calls onSelect with the index of the tab that
    has it now. Keys with a modifier are left alone.

func Tabs(props TabsProps) xango.Node
    Tabs renders a tab strip plus the active tab's content. The caller owns
    which tab is active (see OnSelect), the same controlled-component pattern
    every interactive component in this package uses.

func TagFilter(p TagFilterProps) xango.Node
    TagFilter is a row of chips, All and one for each tag, that picks which tag
    a list is narrowed to.

func Textarea(props TextareaProps) xango.Node
    Textarea renders a styled native <textarea>. Value is set via a "value"
    attribute rather than child text content, the same controlled-input
    convention Slider/DatePicker/ColorPicker already use: domrt patches
    "value" as a real DOM property (see its propAttrs), which is what keeps
    a <textarea> genuinely controlled on the client. A "value" attribute has
    no meaning in the HTML spec for <textarea> though (initial content there
    only ever comes from child text) -- harmless for domrt-mounted pages,
    but if you render this with xango.Render for pure static HTML with no client
    hydration, the initial content won't show up; use xango.El("textarea", ...,
    xango.Text(props.Value)) directly for that case instead.

func Theme(props ThemeProps) xango.Node
    Theme scopes which --gj-* design-token palette applies to its own
    Children -- requires components/base.css, which carries both palettes
    (:root/.gj-theme-light's own light values, .gj-theme-dark's own dark
    overrides). This needs no Go-level context machinery of its own the way
    ContextProvider's own open design question describes: it's a plain wrapping
    <div> carrying a class (or inline custom-property overrides), and CSS
    custom properties already cascade to every descendant element regardless
    of DOM depth -- exactly the same body.dark class-toggle idea OnDesign's own
    applyConfig uses (see that repo's editor/index.html), just scoped to this
    wrapper instead of body, so it composes: a Theme nested inside another Theme
    re-scopes from that point down.

func Toast(props ToastProps) xango.Node
    Toast renders a single transient notification -- unlike Modal/Dialog,
    it has no backdrop and doesn't block interaction with the rest of the page.
    It has no opinion on where it sits on screen (no fixed positioning of its
    own); wrap one or more in your own position:fixed container to stack them.
    Auto-dismissal, if wanted, is the caller's job too (e.g. Window.SetTimeout),
    the same way FileUploader leaves progress tracking to the caller.

func Tooltip(props TooltipProps) xango.Node
    Tooltip wraps Children with a bubble that shows Content on hover or keyboard
    focus. Pure CSS (:hover/:focus-within) -- no JS, no positioning logic to
    keep in sync with anything.

func Transfer(props TransferProps) xango.Node
    Transfer renders "Import" and "Export" button groups, one button per format.
    It is controlled and does no I/O itself: the callbacks choose the file and
    write it.

func Trash(p TrashProps) xango.Node
    Trash shows the documents in the trash, each to Restore or Delete forever,
    and Empty trash to delete them all; Children (the live list) come first.
    With nothing in the trash only the Children are drawn.

func TypingLive(message string, n int) xango.Node
    TypingLive is the live region TypingAnnouncer's sentences go to: polite,
    so it waits for what the reader is saying, and separate from Announcer,
    whose messages (the mode, the number of matches) must not be replaced by
    a typed word. n counts the sentences said: a sentence said twice in a row
    ("a", "a") is still a change of the region, so the reader says it again.

func VersionDiff(p VersionDiffProps) xango.Node
    VersionDiff shows the difference between two versions of a document
    as a list, one item per changed block. It is not coloured text alone:
    each item starts with words a screen reader says ("Inserted paragraph",
    "Deleted heading 2", "Edited paragraph"), added words are <ins> and removed
    words are <del>, and the list opens with a count ("3 changes: 1 inserted,
    1 deleted, 1 edited").

func Versions(p VersionsProps) xango.Node
    Versions lists a document's snapshots, newest first, to open or delete,
    with a button to save a new one.

func WhereSentence(name, text string, anchor, caret int, has bool) string
    WhereSentence says where name's cursor is in text: the paragraph (the lines
    of text, counted from 1, empty ones too), and the few words before the
    caret, or that text is selected. has is false when the person has no cursor
    in the document (a viewer who has not clicked, someone who left the page).

func Wizard(props WizardProps) xango.Node
    Wizard renders a multi-step form flow: a step header strip, the active
    step's content, and Back/Next actions.

type A11yBlock struct {
	Kind    A11yKind
	Level   int
	Ordered bool
	Text    string
	// Runs, when set, are the text again as pieces with their own language: a piece with a Lang is
	// written as a span with a lang attribute, so a screen reader switches voice for it. Their
	// texts, joined, are Text.
	Runs []A11yRun
	// Cells are a table row's cells (Kind A11yTableRow); a table is the
	// consecutive rows, the first of them the header.
	Cells []string
	// Mapped says Start is known: where the block's first rune falls in the editor's text stream. A
	// mapped block carries it as data-gj-start, so the page can turn a position in the copy into a caret
	// in the editor and back (Lead is a prefix of the text that is not in the stream, such as the box of
	// a check-list item). Object is true for a block that stands for one inline object (a picture, a
	// table): the whole of it is that one rune.
	Mapped bool
	Start  int
	Lead   int
	Object bool
	// Caret says the editor's caret is in this block: it is marked aria-current="location".
	Caret bool
}
    A11yBlock is one block of the document, as text.

func MarkCaret(blocks []A11yBlock, offset int) []A11yBlock
    MarkCaret returns the blocks with Caret set on the one that holds the stream
    offset and on no other (the argument is not changed).

func (b A11yBlock) OffsetInBlock(offset int) int
    OffsetInBlock is the reverse of StreamOffset: how many runes of the block's
    text in the copy come before the stream offset (what a host needs to put the
    reader's cursor where the caret is).

func (b A11yBlock) StreamLen() int
    StreamLen is how many runes the block takes in the editor's text stream:
    its text, whatever pieces it is made of (a suggested removal is still in
    the stream), less the Lead that is only in the copy; an object (a picture,
    a table) is one rune.

func (b A11yBlock) StreamOffset(before string) int
    StreamOffset is the stream offset of the position in a mapped block after
    `before` (the text of the block that comes before the position, as the copy
    has it, without the words only a reader hears). Inside an object it is the
    object itself.

type CollabAnnouncer struct {
	// Level is how much is said: CollabOff nothing, CollabImportant the connection and problems, CollabAll
	// that and the people who come and go (the default, "").
	Level string
	// Every is the least time between two sentences (2 seconds if 0). Changes that come sooner are held and
	// said together at the next Update after it.
	Every time.Duration

	// Has unexported fields.
}
    Collaboration cues are visual (a coloured cursor, an avatar that appears).
    CollabAnnouncer turns what changed in a shared session into short sentences
    for a live region (Announcer): people joining and leaving, the connection
    dropping and coming back, a sharing problem. Changes are grouped ("Ana and
    Bo joined") and spaced (at most one sentence per Every), so a busy session
    does not talk over the person.

func (a *CollabAnnouncer) NoteComment(author string)
    NoteComment records that someone else added a comment; it is said, with the
    next sentence, at level CollabAll ("Bo commented." or "3 new comments.").

func (a *CollabAnnouncer) NoteMerged(n int)
    NoteMerged records that n changes made while offline met the shared document
    when the connection came back ("3 changes were merged."). It is said at the
    levels CollabImportant and CollabAll: it says that work was kept, which the
    person needs to know whoever else is there.

func (a *CollabAnnouncer) NoteRejected(n int)
    NoteRejected records that n of the person's changes could not be applied
    (the server refused them: "A change could not be applied."). Said at
    CollabImportant and CollabAll.

func (a *CollabAnnouncer) NoteReply(author string)
    NoteReply records that someone else replied to a comment; it is said at
    level CollabAll ("Bo replied." or "3 new replies.").

func (a *CollabAnnouncer) NoteResolved()
    NoteResolved records that someone else resolved a comment thread ("A comment
    thread was resolved." or "3 comment threads were resolved."), said at level
    CollabAll.

func (a *CollabAnnouncer) Pending() bool
    Pending reports whether something has changed that has not been said yet
    (held by the spacing), so a host can call Update again a little later.

func (a *CollabAnnouncer) Update(now time.Time, online bool, people []string, problem string) string
    Update takes the session as it is now (online or not, the names of the other
    people, the problem if sharing is not working) and returns the sentence to
    say now, or "". The first call only remembers the state.

type DataView[T any] struct {
	Page     int
	Search   string
	SortKey  string
	SortDesc bool

	Items      []T
	Total      int
	TotalPages int
	Loading    bool
	Err        error
	// Has unexported fields.
}
    DataView owns the paginated/filtered/sorted query state for a dataset
    fetched from some backend, and hands DataTable/Grid already-loaded data as
    plain props -- the same "component is a pure function of props, networking
    is the caller's job" split Collab's own doc comment already describes for
    that component, just for a data-*source* rather than a permissions gate.
    It renders nothing of its own -- docs/ROADMAP.md's own task #129 entry left
    "does DataView end up a real third visual component, or just a documented
    pattern" as part of the design work; a plain state-owning generic type
    turned out to need no rendering of its own at all, since DataTable/Grid
    already take already-rendered Rows/Items as plain props.

    Typical use: construct with NewDataView, call Load once, then wire
    DataTableProps (or GridProps)'s own Search/Pagination fields to
    SearchProps()/PaginationProps(), and Rows/Items to a mapping over Items
    built with each T's own real fields -- SetPage/SetSearch/ SetSort (called by
    those wired callbacks) each reload and update Items/Total/TotalPages/Err in
    place, ready for the next re-render.

func NewDataView[T any](props DataViewProps[T]) *DataView[T]
    NewDataView constructs a DataView starting on page 1 with no search/sort --
    call Load once to populate Items.

func (v *DataView[T]) Load() error
    Load calls Fetch with the current Page/Search/SortKey/SortDesc and
    updates Items/Total/TotalPages/Err. Loading is only ever true for the
    duration of this call itself, from this type's own point of view --
    running it off the main goroutine and re-rendering once it returns (so
    Loading ever has a chance to actually paint) is the caller's job, the same
    async-caller-drives-it split FileUploader/ Search already take for their own
    async work.

func (v *DataView[T]) PaginationProps() PaginationProps
    PaginationProps returns a ready-to-use Pagination configuration bound to
    this DataView's own current Page/TotalPages, calling SetPage on change.

func (v *DataView[T]) SearchProps() SearchProps
    SearchProps returns a ready-to-use Search configuration bound to this
    DataView's own current Search, calling SetSearch on change. Suggestions/Open
    are left zero: DataView's own Search is a plain server-side filter,
    not Search's own autocomplete-suggestions half.

func (v *DataView[T]) SetPage(page int) error
    SetPage sets Page (clamped to at least 1) and reloads.

func (v *DataView[T]) SetSearch(search string) error
    SetSearch sets Search, resets Page to 1 (a new search invalidates whatever
    page the old result set was on), and reloads.

func (v *DataView[T]) SetSort(key string, desc bool) error
    SetSort sets SortKey/SortDesc and reloads. DataTableProps.OnSort's own
    callback receives exactly the clicked column's Key; a caller wiring this
    up decides whether that means flipping SortDesc (same key clicked again)
    or starting fresh ascending (a different key), the same "caller decides
    asc/desc toggling" split DataTableProps. OnSort's own doc comment already
    describes.

type DataViewProps[T any] struct {
	Fetch    func(DataViewQuery) (DataViewResult[T], error)
	PageSize int // defaults to 20 if <= 0
}
    DataViewProps configures DataView. Fetch is the only required field:
    the actual network/query logic a real backend needs; DataView itself owns
    only the *state* (current page/search/sort) and when to call it, never the
    wire format.

type DataViewQuery struct {
	Page     int // 1-indexed
	PageSize int
	Search   string
	SortKey  string
	SortDesc bool
}
    DataViewQuery is one request DataView's own Load makes through Fetch --
    deliberately abstract over which real pagination/filter/ sort protocol a
    backend actually speaks (JSON:API, OData, a gojiberry-defined convention,
    GraphQL, a plain bespoke REST endpoint, ...): docs/ROADMAP.md's own task
    #129 entry left that choice open as a real design question, and different
    apps reasonably want different ones, so a Fetch adapter translates this
    generic shape into whatever real request its own backend needs rather than
    DataView committing to one wire format.

type DataViewResult[T any] struct {
	Items      []T
	Total      int
	TotalPages int
}
    DataViewResult is what a Fetch adapter hands back: Items already
    paginated/filtered/sorted server-side (DataView never repeats that
    work client-side), plus how many exist in total at the current
    PageSize/Search/Sort combination -- Total is a plain item count so a caller
    showing "N results" doesn't need to multiply TotalPages back out by PageSize
    to get it.

type GhostAction int
    GhostAction is what a key did to the ghost text.

const (
	GhostNone    GhostAction = iota // the key is not for the ghost text; let it through
	GhostAccept                     // insert Suffix at the caret
	GhostDismiss                    // hide it
)
type GhostState struct {
	// Word is the whole suggested word, Suffix the part the person has not typed yet.
	Word, Suffix string
	// Prefix is what had been typed when the suggestion was made.
	Prefix string
	// Caret is the caret offset (in runes) the suggestion belongs to; accepting at another caret is refused.
	Caret int

	// Has unexported fields.
}
    GhostState is the suggestion being shown, if any.

func (g *GhostState) Accept(caret int) string
    Accept returns the text to insert at the caret, "" when there is none or the
    caret has moved.

func (g *GhostState) Announcement() string
    Announcement is the polite message for the suggestion now shown, "" when it
    was announced already (typing another letter of the same word says nothing
    again) or nothing is shown.

func (g *GhostState) Clear()
    Clear hides the suggestion (the dismissal is kept).

func (g *GhostState) Key(key string) GhostAction
    Key applies a key (as KeyboardEvent.key, with no modifier held) and says
    what it did: only Tab accepts and only Escape dismisses; every other key,
    Enter and the arrows included, leaves the suggestion unaccepted.

func (g *GhostState) Show(prefix, word string, caret int) bool
    Show offers word for prefix at caret; it returns whether it is shown.
    A word that does not continue the prefix, that is no longer than it, or that
    was dismissed for this prefix is not shown.

type RecipientRow struct {
	// Label says who the key is meant for (an e-mail, a name): a label, not what makes it
	// trusted. Type is "ssh-ed25519", "ssh-rsa" or "age-x25519". Fingerprint is what the
	// owner confirms.

	// Detail is one more line about the key, shown after its fingerprint ("Last used in this
	// browser: 2030-05-01"); empty for none.

	// Uses is how many documents the key can open (this one included); 0 means unknown.
	Uses int
	// Verified marks a key that the store's directory says was published by an account with a

	// e-mail is only a label and the owner confirms the fingerprint.

	// (encrypt.PublishedKey.Attested; ssh-ed25519 keys): shown as a stronger mark, because the

	Attested bool
	// OwnerSigned marks a Verified key that the owner of the address signed with the owner key
	// they hold themselves (encrypt.PublishedKey.OwnerSigned): the strongest mark, because not even
	// the server that runs the directory could have added the key. Set it from a client that
	// checked the evidence itself (directoryclient.Key.OwnerSigned). OwnerEnrolled says the
	// address has an owner key: a Verified key that is not OwnerSigned then gets a note.

	CanRemove     bool
	RemoveBlocked string

	SecondKeyMessage string
	// CreateRecoveryKey makes a recovery key (encrypt.GenerateRecoveryKey), adds its public part as
	// an owner key and returns the secret. The button is shown only when OnRecoveryKey is also
	// set (a key whose secret cannot be shown must not become an owner key). The component hands
	// the secret to OnRecoveryKey and keeps no copy; the host passes it back as RecoverySecret
	// until the person has saved it and OnRecoveryDone is called, and must then drop it: it is
	// shown once. What holds: the component does not keep the secret in the DOM after that
	// ("I have saved it"); the host holds it in memory while it is shown. Go strings cannot be
	// wiped, so a copy may stay in memory until it is collected. Copy and Download
	// (nil leaves the button out) are the host's clipboard and file save.
	CreateRecoveryKey func(ctx context.Context) (secret string, err error)
	OnRecoveryKey     func(secret string)
	RecoverySecret    string
	OnRecoveryDone    func()
	Copy              func(text string)
	Download          func(name, text string)
	// CommitRecoveryKey, when set, makes the recovery key transactional: CreateRecoveryKey only
	// prepares the key (nothing is added to the store yet) and returns its secret, the secret is
	// shown, and the key becomes an owner key only when the person acknowledges they saved it
	// (RecoveryAcknowledged, set by the host from OnRecoveryAcknowledge) and presses the confirm
	// button, which runs CommitRecoveryKey. A key whose secret was never seen is thereby never an
	// owner key. CancelRecoveryKey (nil leaves the button out) drops the prepared key and secret
	// without adding it. Without CommitRecoveryKey the key is already added when its secret is
	// shown, and "I have saved it" only hides the secret (the older behavior).
	CommitRecoveryKey     func(ctx context.Context) error
	CancelRecoveryKey     func()
	RecoveryAcknowledged  bool
	OnRecoveryAcknowledge func(saved bool)

	// RemoveOwner takes an owner key out of the store (each owner row gets "Remove this key",
	// enabled by its row's CanRemove). ReplaceOwner swaps a passkey for a new one; it is offered
	// on the rows of type "passkey-prf". Both ask first (Ask) and say what it does and does not do.
	RemoveOwner  func(ctx context.Context, fingerprint string) error
	ReplaceOwner func(ctx context.Context, fingerprint string) error

	// Publish publishes the owner's keys in the store's key directory (the "Publish my keys"
	// button, shown with the directory picker; nil leaves it out). PublishNotice is the line the
	// host shows after it, or why it could not.
	Publish       func(ctx context.Context) error
	PublishNotice string
}
    RecipientsProps configures Recipients.

type TypingAnnouncer struct {
	// Level is what is said of typed text: TypingOff nothing (the default), TypingWords each word when it
	// is finished (and a word left unfinished for Pause), TypingCharacters each character as it is typed.
	Level string
	// Formatting says changes of the formatting at the caret: "Bold on", "Bold off", and the paragraph
	// style ("Heading 2") when the caret goes into another.
	Formatting bool
	// Lines is reading as the caret moves: the line it goes to when it changes line (the arrow keys up and
	// down, a click). Within a line, TypingCharacters says the character passed over, and either level
	// the text passed over by a move of more than one character (Ctrl+Left or Ctrl+Right).
	Lines bool
	// Every is the least time between two sentences (500 ms if 0). What comes sooner is held and said
	// together at the next Update after it.
	Every time.Duration
	// Pause is how long a word being typed may stand unfinished before it is said (1.5 s if 0).
	Pause time.Duration

	// Has unexported fields.
}
    A canvas gives a screen reader nothing to say when a person types, or moves
    the caret: the keys go to a hidden input whose text is not the document.
    TypingAnnouncer turns what changed in the document into short sentences
    for a live region (TypingLive): the words as they are finished, or each
    character; the line the caret has gone to; a formatting change at the caret
    ("Bold on"). It is a pure state machine: the host gives it the document as
    it is after each change (Update) and says what it returns. What it says is
    spaced (at most one sentence per Every, the rest held and said together)
    and bounded, so quick typing is not read as a queue that runs on after the
    person has stopped.

    Preferences: Level (off, words, characters), Formatting and Lines, each
    on its own, because what a person wants differs, and a screen reader may
    already echo what the hidden input receives.

func (a *TypingAnnouncer) Pending() bool
    Pending reports whether something is held (or a word is unfinished),
    to be said by a later Update: the host calls Update again after Every.

func (a *TypingAnnouncer) Reset()
    Reset forgets the document and what is held: the next Update only remembers
    (use it when the editing stops, or the document is replaced, so the whole
    text is not taken for a paste).

func (a *TypingAnnouncer) Update(now time.Time, cur TypingState) string
    Update takes the document as it is now and returns the sentence to say now,
    or "".

type TypingState struct {
	// Text is the editor's text and Caret the offset of the (first) caret in it, in runes.
	Text  string
	Caret int
	// Line is the text of the line the caret is on (as drawn, so a wrapped line is the part on screen) and
	// LineStart its offset in Text; two lines with the same text are told apart by the offset.
	Line      string
	LineStart int
	// Marks are the names of the formatting at the caret ("Bold", "Italic") and Block the name of the
	// paragraph style ("Heading 2"; "" for plain text).
	Marks []string
	Block string
}
    TypingState is the document as the announcer needs it, after a change.
