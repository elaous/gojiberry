package devreload // import "github.com/elaous/gojiberry/devreload"

Package devreload lets an xango SSR server opt into a live-reload dev
loop with two calls: wrap rendered HTML with (*Reloader).Wrap and mount
(*Reloader).Handler wherever the injected script polls. A browser tab reloads
itself once that endpoint reports a different version than the one the page
was rendered with -- i.e. once the process serving it has been rebuilt and
restarted, the other half of the loop devwatch (see the sibling devwatch
package) drives.

This began as examples/canvas-app's own hand-rolled devVersion/ devReloadScript
pair, wired into that app's net/http mux by hand; this package is that same
mechanism generalized so any xango server (net/http, Gin, Echo, Encore's
raw endpoints, ...) can use it without re-deriving it, matching xango's own
opt-in-per-call style rather than a magic global. A Reloader is nil-safe
everywhere a *Reloader is accepted (Wrap becomes a no-op, Handler serves 404)
specifically so callers can keep one code path and pass nil in production
instead of branching on a devMode bool at every call site -- see canvas-app's
devserver for exactly that usage.

FUNCTIONS

func Path() string
    Path returns the fixed endpoint Handler must be mounted at (e.g.
    mux.Handle(devreload.Path, reloader.Handler())), so callers never need to
    hardcode "/__dev/version" themselves.


TYPES

type Reloader struct {
	// Has unexported fields.
}
    Reloader tracks one server process's identity for the dev-reload loop.
    The zero value is not usable; construct with New.

func New() *Reloader
    New constructs a Reloader whose version is this process's own start time
    -- enough on its own to differ after every restart devwatch performs,
    no separate file or signal needed to bump it.

func (r *Reloader) Handler() http.Handler
    Handler serves r's version at versionPath as an uncached, plain-text
    response, for whatever router the caller mounts it on. Calling Handler on
    a nil *Reloader returns a handler that always answers 404, so registering
    it unconditionally (dev or not) is safe -- production simply gets a 404 for
    a path nothing in a production build ever requests, rather than the caller
    needing to skip registration too.

func (r *Reloader) Wrap(html string) string
    Wrap injects a small polling script into html, just before its closing
    </body> tag (appended at the end if html has none). The script fetches
    versionPath every 500ms and reloads the tab the first time the response
    differs from r's own version, treating a failed fetch (the old process has
    exited but the new one isn't listening yet) as "not ready", not "reload
    now". Wrap on a nil *Reloader returns html unchanged, so production code
    paths can pass a nil Reloader instead of branching on a devMode flag.
