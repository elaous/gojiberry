# axe-core (vendored)

`axe.min.js` is [axe-core](https://github.com/dequelabs/axe-core) 4.10.2, unmodified, from the npm package
(`npm pack axe-core@4.10.2`). It is licensed under the Mozilla Public License 2.0 (see `LICENSE`); the license
applies to this file only. It is used by `Tab.Axe` in the browser tests to check the pages for accessibility
violations. To update: pack the new version, replace both files, and run the accessibility tests.
