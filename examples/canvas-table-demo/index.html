Canvas table

Starts in view mode (read-only); switch to edit mode, then click a cell to edit. Tab / Shift+Tab / Enter / arrows move around; hover the table: click the + on the right edge or bottom to add a column or row, a grip (≡) above a column or left of a row to select it and open its menu, or the 2×2 icon in the corner to select the table.
